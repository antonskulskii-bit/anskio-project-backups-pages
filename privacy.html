Anskio Project Backups

Privacy Policy

Last updated: October 22, 2026

Purpose

Anskio Project Backups is a personal tool used by its owner to create and retain source-code backups for the owner’s own projects.

Google Drive access

The application uses the Google Drive API with the drive.file permission. This access is used to upload, verify, and restore backup files that the application creates or selects for its own use.

Backup data

Backup archives are encrypted locally before upload. The application uses Google Drive to store the encrypted backup files.

Data sharing

The application does not sell user data or provide user data to advertisers.

OAuth tokens

OAuth tokens are stored locally by the owner and are not published on this website.

Contact

For privacy questions, contact visa.anskio@gmail.com.
